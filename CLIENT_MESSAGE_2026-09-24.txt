1. EntityKey explanation and report update

EntityKey identifies the exact table row that changed. For example, {"UnitID":123} means Unit table row 123. For UPR_CLOSURE, the key contains both UPRAncestry and DescendantUPRID because both values are needed to identify that relationship. I used JSON to retain the column names and all key values consistently across the audited tables.

I have updated the audit report to display readable values such as [UnitID] = 123, or [UPRAncestry] = 10025; [DescendantUPRID] = 10026. The stored keys and audit history remain unchanged. The new @RawRecordKey option allows the original JSON display when needed.

If you see a negative EntityRecordID, that is an internal audit reference used for composite/text keys. It is not a negative property UPRID or an error.
